# Casa Forma — protótipo de checkout arquitetônico

Protótipo estático responsivo e instalável (PWA), pronto para GitHub Pages.

## Publicar no GitHub Pages
1. Crie um repositório público no GitHub.
2. Envie todos os arquivos desta pasta para a raiz do repositório.
3. Em **Settings → Pages**, selecione **Deploy from a branch**, branch `main` e pasta `/ (root)`.
4. Aguarde a publicação e compartilhe o endereço `https://SEU-USUARIO.github.io/NOME-DO-REPOSITORIO/`.

## O que funciona
- Catálogo com filtros e busca.
- Detalhes de projetos demonstrativos.
- Seleção de adicionais e atualização automática do total.
- Carrinho/resumo e formulário de checkout.
- Preparação do pedido e envio do resumo por WhatsApp.
- Link de contato com Heitor, desenvolvedor.
- Manifesto e service worker para instalação como aplicativo.

## Antes de produção
Os projetos, preços, imagens e textos são ilustrativos. O protótipo não cobra pagamentos nem libera arquivos. Para produção, substituir os dados de exemplo, inserir o WhatsApp/identidade comercial do cliente, validar os aspectos técnicos e integrar um gateway de pagamento (ex.: Mercado Pago, Asaas ou Stripe), backend, gestão de pedidos e entrega segura dos arquivos. O nome "Casa Forma" é uma marca provisória.
